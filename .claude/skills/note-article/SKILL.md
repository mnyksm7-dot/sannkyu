# note.com 記事作成自動化

note.com に貼り付けてそのまま使える記事の原稿を作成する。**実際の投稿・下書き保存は行わない**(note.com に公開APIがなく、自動ログインもしない方針のため)。ここで作るのはあくまで原稿とサムネイルのソース。

## 手順

1. **テーマを確認する。** ユーザーの発言からテーマ・キーワード・想定読者・トーン(カジュアル/ビジネスなど)を読み取る。曖昧な場合は簡潔に確認してから書き始める。
2. **出力先を決める。** `output/<YYYYMMDD>-<slug>/article.md` に保存する。`slug` はテーマから短い英数字スラッグを作る(例: テーマ「Claude Codeの使い方紹介」→ `claude-code-usage`)。日付は実行日。
3. **記事を書く。** `article.md` に以下の構成で書く:
   - `# タイトル` — 読者の興味を引く具体的なタイトル
   - リード文(2〜3文) — 記事の要点とこの記事を読むメリット
   - `##` 見出しで区切った本文(3〜6セクション程度)
   - まとめ・締めの一言(CTAがあれば添える)
   - 記事末尾に `## タグ候補` として note.com 用のハッシュタグ候補を5〜10個列挙する
   - 分量の目安は日本語本文でおよそ2000〜4000文字(ユーザーが別の分量を指定した場合はそちらに従う)
4. **完了したら伝える。**
   - `article.md` のパスを伝える
   - サムネイルも欲しいと言われたら、または未生成なら `note-thumbnail` スキルの利用を提案する
   - note.com への実際の公開・下書き保存はユーザー自身が手動で行う必要があることを明記する
