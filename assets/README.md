# 写真の配置について

このフォルダに以下5枚の実店舗写真を配置してください（ファイル名を揃えるだけでOKです）。

- `hero.jpg`　… トップの大きい写真（横長・1920x1080目安）
- `mirror.jpg`　… ABOUTセクション（正方形に近い比率）
- `counter.jpg`　… カウンター席（縦長）
- `sofa.jpg`　… ソファ席
- `bar.jpg`　… ボトル・カウンター

画像は容量が大きいとページ表示が遅くなり、SEO（表示速度）評価が下がります。
アップロード前に1枚あたり300KB程度以下（長辺1600px前後）にリサイズすることをおすすめします。
[squoosh.app](https://squoosh.app/) などの無料ツールで手軽に圧縮できます。
