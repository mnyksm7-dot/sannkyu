# Claude Codeの使い方入門:今日から始める開発効率化

「AIにコードを書かせてみたいけど、何から始めればいいかわからない」——そんな人向けに、Anthropicが提供するCLIツール「Claude Code」の使い方を、インストールから実践的な使いこなし方まで紹介します。読み終える頃には、自分のプロジェクトで today から触ってみたくなるはずです。

## Claude Codeとは何か

Claude Codeは、ターミナル上で動く対話型のAIコーディングアシスタントです。チャット画面にコードを貼り付けて質問するのとは違い、実際のリポジトリの中に入り込んで、ファイルの読み書き・検索・テストの実行・Gitの操作までを一貫して行えるのが最大の特徴です。人間のエンジニアに「このバグを直しておいて」と頼む感覚に近い体験ができます。

具体的には次のようなことが可能です。

- コードベース全体を横断的に検索し、関連ファイルを特定する
- バグの原因を調査し、修正パッチを実際のファイルに適用する
- テストを実行し、失敗の原因を分析して直す
- コミットメッセージを添えてGitにコミット・プッシュする
- 新機能の実装計画を立ててから着手する(プランモード)

## 導入方法

Claude Codeはnpm経由でインストールできます。

```
npm install -g @anthropic-ai/claude-code
```

インストール後、対象のリポジトリのディレクトリで `claude` コマンドを実行するだけで起動します。初回起動時にAnthropicアカウントでの認証を求められるので、案内に従ってログインすれば準備完了です。

## 基本的な使い方

起動すると対話プロンプトが表示されるので、あとは日本語や英語で普段の指示を出すように話しかけるだけです。

- 「このリポジトリの構成を説明して」と聞けば、READMEやディレクトリ構成を読み込んで要約してくれる
- 「◯◯のバグを直して」と頼めば、関連ファイルを探し、修正して、必要ならテストまで実行してくれる
- 「新しいAPIエンドポイントを追加して」と頼めば、既存のコードの書き方に合わせて実装してくれる

作業内容が複雑になりそうなときは、いきなり実装させず「プランモード」で計画だけ立ててもらい、内容を確認してから実行に移すと安心です。想定外の大規模な書き換えを防げます。

## 効率よく使うためのコツ

1. **具体的に指示する**:「良い感じにして」ではなく、「この関数の型を厳密にして、テストも追加して」のように、期待する結果を明確に伝える。
2. **小さく区切って依頼する**:一度に大きな機能を丸ごと頼むより、レビューしやすい単位に分けたほうが、意図しない変更を早めに見つけられる。
3. **既存のコードスタイルを尊重してもらう**:プロジェクトにコーディング規約があるなら、そのことを伝えておくと一貫性のあるコードになりやすい。
4. **CLAUDE.mdを活用する**:プロジェクトのルールや注意点をまとめたファイルを用意しておくと、毎回同じ説明を繰り返さずに済む。
5. **危険な操作は必ず確認する**:強制pushやファイル削除など、取り返しがつかない操作を頼むときは、実行前に内容を確認する習慣をつける。

## こんな場面で活躍する

- 慣れないコードベースに参加したばかりで、まず全体像を把握したいとき
- 単調なリファクタリングや、大量のファイルへの同じ修正を横展開したいとき
- テストが落ちているが原因調査に時間を割きたくないとき
- ドキュメントやコミットメッセージの整備など、後回しにしがちな作業を片付けたいとき

## まとめ

Claude Codeは、単なるコード生成ツールではなく、実際のリポジトリの中で「一緒に作業してくれる同僚」のような存在です。最初は簡単なタスクから任せてみて、指示の出し方や確認のタイミングに慣れていくのがおすすめです。慣れてくると、これまで後回しにしていた細かい改善やリファクタリングにも気軽に手をつけられるようになります。まずは自分の手元のプロジェクトで、小さな一つのタスクから試してみてください。
