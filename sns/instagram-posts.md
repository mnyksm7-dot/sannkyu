# Instagram投稿ドラフト(note記事と連動)

各note記事につき、Instagramではカルーセル(複数枚)投稿でダイジェストを見せ、
「続きが気になる状態」でnoteに送客する。画像は `sns/images/` の同名ファイルを使用。

キャプションの型は共通:
```
[フック(1行)]

[本文:記事の核心を要約、ただし結論は書き切らない]

―――
続きはnoteで📝(プロフィールのリンクから)
#タグ #タグ #タグ
```

## 投稿1:朝のルーティン
画像: `sns/images/01-morning-routine.png`

**カルーセル構成**
1. 表紙:「アラームを止めた瞬間、もう一日は始まっている」
2. 「起きてすぐスマホを見る朝、実はやめてから気づいたことがある」
3. 「変わったのは行動じゃなく、一日の“基準点”だった」
4. 「実際に試した3つの朝ルーティン、続かなかった理由は…」(note記事へ)

**キャプション**
```
アラームを止めた瞬間、もう一日は始まっている。

起きてすぐスマホを見るのが当たり前だった私が、
「情報を見る前に3分だけ自分の時間を作る」に変えただけで、
一日の"だるさ"の始まり方が変わった。

試した3つのルーティンのうち、続かなかったものと、
今も続けているものをnoteにまとめました。

―――
続きはnoteで📝(プロフィールのリンクから)
#エッセイ #朝活 #習慣化 #ライフスタイル #日常
```

## 投稿頻度の目安

- Instagram:週2〜3投稿(note公開と同時、または1〜2日後に「ダイジェスト」として投稿)
- ストーリーズ:投稿直後に「新しい記事あげました」+ noteへのリンクスタンプ
- note側の公開 → Instagramで告知、という順序を必ず守る(逆にすると本編が薄まる)
