# Instagramプロフィール設計

noteのブランド「sannkyu(39/サンキュー)」をInstagramでも統一して使う。
コンセプトは「日常の中の小さな『ありがとう』を綴るエッセイアカウント」。
Instagramは新規読者との接点、noteは本編(収益化の場)という役割分担にする。

## アカウント名・ユーザーネーム案

- 表示名:`39(サンキュー) | 日常のありがとうエッセイ`
- ユーザーネーム案:`@sankyu.essay` / `@39_kurashi` / `@sankyu_note`(空いているものを選ぶ)

## 自己紹介文(bio, 150文字以内)

```
日常の中の、ちいさな「ありがとう」を綴る📝
頑張りすぎない暮らし / 人間関係 / お金の話
続き・本編はnoteで🔻
```

- 1行目:アカウントの世界観(このリポジトリの記事群と一致させる)
- 2行目:扱うテーマを列挙(記事ジャンルと一致させ、読者に期待値を伝える)
- 3行目:noteへの導線を明言(「続きはnoteで」は毎回のキャプションでも繰り返す合言葉にする)

## プロフィール画像

`sns/images/profile-icon.png`(このリポジトリ内で生成予定)を使用。
シンプルなアイコン調で、noteのアイコンと同じものを使い、"同一人物・同一ブランドである"ことを一目でわからせる。

## リンク(プロフィールのリンク欄)

Instagramは1リンクしか貼れないため、以下のいずれかを設定する。

- 最短:note のプロフィールURL(`https://note.com/(アカウント名)`)を直接貼る
- 発展形:リンクまとめサービス(lit.link や potofu など)を使い、
  「最新記事」「マガジン」「サポート」の3つに分岐させる

最初は運用の手間を減らすため、**noteのプロフィールURL直貼り**で始めることを推奨する。

## ハイライト(ストーリーズハイライト)構成

固定表示するハイライトを用意し、初訪問者が迷わないようにする。

1. **「はじめまして」**:自己紹介、このアカウントで発信していること
2. **「note→」**:noteの使い方、有料記事の案内、マガジン紹介
3. **「読者の声」**:コメント・感想のスクリーンショット(信頼形成)
4. **「よく読まれた記事」**:反応が良かった投稿のアーカイブ

## 固定投稿(フィード上部に固定する1〜3件)

1. 自己紹介投稿(このアカウントは何をする場所か)
2. 一番読まれているnote記事の要約カルーセル
3. noteの収益化コンテンツ(マガジン/メンバーシップ)の案内

## 運用ルール

- 投稿本文の最後は毎回「続きはnoteで(プロフィールのリンクから)」で統一する
- ストーリーズでは note記事へのリンクスタンプを毎投稿後に使う(フォロワー数条件を満たしていれば)
- プロフィールの世界観(色味・トーン)は `articles/thumbnails/` のサムネと揃え、
  「note記事のダイジェスト版がInstagram」という一貫性を保つ
