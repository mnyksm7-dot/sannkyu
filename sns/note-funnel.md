# Instagram → note 送客の仕組み

InstagramとNoteは役割を分ける。**Instagramは「出会いの場」、noteは「本編・収益化の場」**。
この前提が崩れる(Instagramだけで満足されてしまう)と、note誘導が機能しなくなるので注意する。

## 送客の導線(4つのタッチポイント)

1. **プロフィール欄のリンク**(常設・最重要)
   `sns/instagram-profile.md` の通り、note のプロフィールURLを設定。
   フィード投稿からは直接リンクを貼れないため、これが唯一の"常設ドア"になる。

2. **投稿キャプションの文末**(毎投稿・必須)
   `sns/instagram-posts.md` のテンプレ通り、必ず
   ```
   ―――
   続きはnoteで📝(プロフィールのリンクから)
   ```
   を入れる。これを"合言葉"として毎回統一し、フォロワーに行動パターンとして覚えさせる。

3. **ストーリーズのリンクスタンプ**(投稿直後・任意/条件付き)
   フィード投稿の直後にストーリーズを1本出し、「新しい記事あげました」+ noteの記事URLへの
   リンクスタンプを貼る。フィードだけでは動かない層も、ストーリーズのワンタップなら動きやすい。

4. **ハイライト「note→」**(常設・新規フォロワー向け)
   プロフィールのハイライトにnoteへの誘導だけをまとめた枠を常設し、
   フォロー直後のユーザーがどこからでもnoteに辿り着けるようにする。

## カルーセルの「切り方」の原則

Instagramのカルーセルは、note記事の**前半(無料部分)だけ**を要約して見せる。
`monetization-guide.md` で定義した「前半=気づき/後半=具体策」の構成と対応させ、

- Instagram:気づき(共感パート)まで
- note:具体策・実践・数字(有料/本編パート)

を見せる。これにより「気になるけど、続きはnoteでしか読めない」状態を自然に作る。
逆に、後半の具体策までInstagramで書いてしまうと、note誘導は機能しなくなるので避ける。

## 数値で見る運用チェック

月1回、以下を確認して `articles/ideas.md` や投稿頻度を調整する。

| 指標 | 見る場所 | 目安アクション |
|---|---|---|
| プロフィールへのタップ率 | Instagramインサイト | カルーセル表紙の"引き"が弱ければ改善 |
| リンククリック数 | Instagramインサイト(プロフィール) | 低ければキャプションのCTA文言を見直す |
| note側の流入元 | note公式のPV分析 | Instagram経由が伸びているテーマを重点化する |
| note記事の続き購読率 | note有料記事の購入数 | 前半/後半の切り方が適切かを判断する材料にする |

## 最初の1ヶ月の具体的な動き方

1. Instagramプロフィールを `instagram-profile.md` の内容で整える
2. note側で5本の下書き記事(`articles/`)を投稿(最初は全部無料でOK)
3. 各記事の翌日に、対応するInstagramカルーセル(`instagram-posts.md`)を投稿
4. 投稿直後にストーリーズでリンク告知
5. 1ヶ月経過後、Instagramインサイトとnoteの流入元を見比べ、反応の良かったテーマを次の記事ネタに反映(`articles/ideas.md` を更新)
